# 🏀 NBA – Analysis and Insight Dashboard

## 📌 Project Overview
The NBA Analysis and Insight Dashboard is a comprehensive and interactive data analytics project built to explore, analyze, and visualize historical NBA data across multiple seasons. The primary goal of this dashboard is to transform large volumes of raw NBA match, team, and player data into meaningful insights that support performance evaluation, trend analysis, and data-driven decision-making.

This dashboard allows users to understand how teams and players have performed over time by analyzing key performance indicators such as total wins, total games played, total points scored, win percentages, player average goals, and home versus away performance. The project is designed with a clean, intuitive layout that enables quick exploration and comparison across teams, players, cities, conferences, and seasons.

---

## 🎯 Project Objectives
- Provide a centralized view of NBA performance metrics
- Analyze team-wise and player-wise performance trends over multiple seasons
- Compare win percentages across teams and conferences
- Identify top-performing players based on average goals
- Evaluate the impact of home and away games on team performance
- Enable interactive exploration using filters and slicers
- Showcase data visualization and storytelling skills for analytics portfolios

---

## 📊 Key Performance Indicators (KPIs)
- Total Wins across all seasons
- Total Games Played
- Total Points Scored
- Average Player Performance Metrics
- Conference-wise Wins (East vs West)
- City-wise Win Distribution
- Team Win Percentage
- Home Wins vs Away Wins
- Home Points vs Away Points

---

## 📈 Dashboard Visualizations
- **Total Wins, Games, and Points Cards** for high-level overview
- **Conference-wise Wins Bar Chart** to compare East and West performance
- **City-wise Wins Pie Chart** to show geographic distribution of success
- **Team Win Percentage Table** for performance ranking
- **Player Average Goals Bar Chart** highlighting top NBA players
- **Total Points by Season Chart** to identify scoring trends over time
- **Total Points by Team Chart** to compare offensive strength
- **Home vs Away Points Comparison** to analyze venue impact
- **Home Wins vs Away Wins Chart** for team-level performance evaluation
